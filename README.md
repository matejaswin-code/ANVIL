# ANVIL
a 3d model generator using image input or text input. anvil is powered by hunyuan3d's latest model and is optimized for 12gb vram and 32gb ram with help of a custom built ai model switcher to juggle the llm(from lm studio), image generator(FLUX) and hunyuan3d. it also has trellis.2 support but it has not been implemented due to liscesning issues.
